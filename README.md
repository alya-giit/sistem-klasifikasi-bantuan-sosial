# Sistem Klasifikasi Kelayakan Penerima Bantuan Sosial Menggunakan Naive Bayes

Aplikasi berbasis Java untuk mengelola data pengguna, kriteria penilaian, program bantuan sosial, pengajuan calon penerima, serta perhitungan klasifikasi kelayakan penerima bantuan sosial menggunakan metode **Naive Bayes**.
